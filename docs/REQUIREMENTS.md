# Контракт и конфигурация · 09.10.2026

| Проверка | Основание | Статус источника |
|---|---|---|
| Вход JWT + wss, без localhost | S-1 исходного tests/live-rooms.spec.js | тестовое ожидание; живой контракт текущей сборки предстоит сверить |
| H-1 A без продукта, старая ссылка → запрет | исходный H-1; исторический ретест исходного набора | исторический факт; актуальные роли/Product обязательны |
| Lock входа → 423; ошибочный пароль → отказ | исходный тест «Вход» | текущая логика не перепроверена |
| Три разные записи ready + playable | сохранённый UI-контракт: statusLabels.ready и item.playable; исходный M-5, цель записи | ready/playable — реализация UI; время обработки 120с — бюджет теста, не обещанный SLA |
| finish + unpublish, сервер finished/false | сохранённый UI-контракт: finished/cancelled, liveRoom.is_published, admin.live-rooms.unpublish | код подтверждает поля/маршрут; интеграционное поведение новой версии не проверено |
| M-10 ≤90с | исходный тест; исторические наблюдения сообщают разброс 1–2.5 мин | контракт спорный: не менять 90с молча, согласовать допустимый timeout presence |
| M-9 transient loading | исходный M-9 | быстрый ответ может скрыть краткий индикатор; падение только этой проверки расследовать как timing/контракт |

Конфигурация: публичная/персональная/продуктовая видимость; опубликована/нет; постоянная/нет; locked; password; chat pause; роль host/moderator/student/staff. Настройка влияет на ожидаемый доступ, поэтому заранее записать исходные значения, пользователя/id/школу, продукт/тариф, текущую сборку. Код не является самостоятельным подтверждением бизнес-требования. Нет исходного ТЗ/Figma/решения — вопрос проджекту, не выдуманное ожидание.

Реальный playback: после ready/playable открыть «Смотреть», play с пользовательским жестом, убедиться currentTime растёт и есть видимые/слышимые фрагменты. Chromium не обязательно поддерживает текущий HLS путь: проверить фактический плеер и Safari. При запрете инструмента BLOCKED, не PASS. Автоматический playback здесь пока не реализован, чтобы не выдать локальную догадку за контракт.
