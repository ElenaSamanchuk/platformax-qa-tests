# iOS: автономная read-only проверка главной

`scripts/native_home_smoke.py` переиспользован без изменения байтов из текущего
QA PlatformaX Student от30.10.2026. Это отдельный Python CLI, он не входит в
Playwright, `npm test` или CI и не вызывает модель либо платный AI API.

Проверяет foreground bundle до и после чтения, установленную version/build,
все ожидаемые видимые подписи главной и отсутствие явно запрещённых сообщений.
Пустой экран не проходит. Другой bundle/build даёт BLOCKED до чтения страницы.
Результат PASS/FAIL/BLOCKED и exit0/1/2. Не запускает приложение, не создаёт WDA
session, не нажимает элементы, не меняет сервер или настройки и не сохраняет
полный source. UDID/session/cookies в репозитории отсутствуют.

## Подготовка и команда

Нужны Python3.9+, установленные `facebook-wda`, `pymobiledevice3`, существующий
подключённый iPhone и уже работающая разрешённая WDA-сессия. Эксклюзивный слот и
device lock согласуются отдельно по правилам команды: флаг `--released` является
подтверждением оператора, а не автоматическим получением блокировки.

Оператор заранее открывает нужную главную. Приватный JSON конфигурации содержит
`bundle`, `version`, `build`, непустой `required_labels` и `forbidden_labels`.
Подписи берутся из подтверждённой текущей главной. Не публиковать реальные имена,
школы, курсы, UDID, session-файл и результат с приватными подписями.

```sh
# Шесть синтетических проверок parser/guards, без устройства и зависимостей WDA:
python3 scripts/native_home_smoke.py --self-check

# Только в разрешённом эксклюзивном слоте, на уже открытой главной:
python3 scripts/native_home_smoke.py --released \
  --udid "$QA_IPHONE_UDID" --session-file "$QA_WDA_SESSION_FILE" \
  --config "$QA_PRIVATE_HOME_CONFIG" --out "$QA_NEW_PRIVATE_RESULT"
```

`--out` должен указывать новый файл. Без release/device/session входа transport
не вызывается. Общие env Playwright здесь не используются: это native metadata
и WDA GET, не браузерный тест и не вход на произвольный сервер.

- Исходный live-результат и приватная конфигурация сохранены в QA-проекте,
  они не опубликованы. В переносе скрипт побайтно совпадает с проверенным исходником

Это смоук идентичности/главной. Авторизация, курсы, файлы, домашние задания,
платежи, push, клавиатура, доступы, Admin и Kinezio этим запуском не приняты.
Ручные проверки этих функций нельзя выдавать за автономный регресс.
