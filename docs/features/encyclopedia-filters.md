# Энциклопедия: фильтры

Источник контракта: задание на тестирование от 29.10.2026. Четыре категории;
значения одной категории объединяются через «или», разных категорий через «и».
Второе нажатие оборудования исключает его, третье снимает исключение. Пустая
выдача объясняет отсутствие результатов и предлагает сброс. Группы раскрываются
и сворачиваются; возврат из урока сохраняет выбор и результаты.

`tests/encyclopedia-filters.spec.js` использует общий origin guard, кооперативный
lock и read-only browser context. Новых объектов и отметок просмотра не создаёт;
все запросы кроме GET/HEAD/OPTIONS блокируются. Видео и trace отключены. Приватные
сессия, путь продукта и ID ожидаемого пользователя передаются отдельно:

```sh
ENC_STORAGE_STATE=/private/session.json \
ENC_PRODUCT_PATH=/products/123 \
ENC_EXPECTED_USER_ID=123 \
QA_RUN_APPROVED=1 \
QA_DATA_LOCK_DIR=/private/new-encyclopedia.lock \
npx playwright test tests/encyclopedia-filters.spec.js --output=/private/results
```

`BASE_URL` берётся из локального окружения. Не хранить значения реального стенда,
учётки, storageState, сырые данные и артефакты в Git. Слот чтения согласовывается
до `QA_RUN_APPROVED=1`; один worker не защищает от чужого процесса.

Пять сценариев:

- ENC-1: независимый оракул по текущим facets уроков, расширение OR, сужение AND,
  включение/исключение/снятие оборудования, полное сравнение ссылок и счётчиков групп
- ENC-2: пустая выдача Шея + Штанга и возвращение обычных разделов через Сбросить
- ENC-3: Показать ещё и Свернуть, переход из результатов к уроку и возврат кнопкой
  Назад с сохранёнными query-параметрами, чипом и полным набором результатов
- ENC-5: отдельный возврат средствами истории браузера с сохранёнными фильтрами
- ENC-4: мобильная эмуляция 390×844, touch/DPR 3; первоначальные аккордеоны,
  Показать все, счётчик результатов, закрытие шторки с сохранением выбора, сброс

Оракул не оценивает смысл автоматических тегов. Группы сравниваются по server
facets; наличие карточек в свёрнутой части DOM не означает их видимость.
Требуются доступный продукт с включёнными фильтрами и данными нужных категорий.
На неподходящей фикстуре падение классифицируется как данные, а не баг продукта.

Реальные телефоны, native-приложения, другие бренды, права/покупка доступа, скорость,
пассивная безопасность и полный визуальный аудит не покрываются этим набором.
Последний прогон: 29.10.2026, тестовая брендовая тема Kinezio. Chromium ENC-1
и ENC-2 PASS (10,2 и 10,5 с); ENC-3 выявляет сброс фильтров после экранного возврата
из урока и намеренно остаётся красным по требованию. WebKit ENC-2 PASS 13,1 с,
Firefox ENC-2 PASS 17,0 с. Финальный целевой запуск ENC-3/4/5: 1 FAIL / 2 PASS за 58,1 с, exit 1.
ENC-3 FAIL 32,5 с: экранный возврат сбрасывает query с выбранной областью тела.
ENC-4 PASS 10,1 с: мобильная шторка. ENC-5 PASS 12,3 с: история браузера сохраняет
выбор и полную выдачу. Всего по пяти сценариям: 4 PASS, 1 FAIL; это результаты
последовательных целевых запусков на одной проверяемой сборке, не один полный прогон.
Красное ожидание ENC-3 не отключено и не заменено разрешением сброса фильтров.

Изначальные ошибки локаторов исправлены без изменения продуктового контракта:
категории фильтров исключены из списка групп результатов, изменение aria-label
исключённого оборудования учтено; у dialog с fixed-детьми проверяются видимые
элементы. Служебный debugbar тестового стенда закрывается штатной кнопкой, поскольку
его минимизированная панель перехватывала Сбросить. Это артефакты проверки, не баги.

Новых серверных объектов, отметок и попыток нет. Контексты закрываются, собственный
lock освобождается в finally, включая ошибки и timeout. В Git нет сессии/фикстуры
и приватных результатов.
