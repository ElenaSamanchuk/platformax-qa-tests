# GF-6316: PopovichFit, режимы и интерфейс

Накопленный регресс проверяет подтверждённую ошибку M1: контейнер таймкодов в избранной силовой тренировке должен помещаться в карточку на 1440/390/320. Внутренняя горизонтальная прокрутка допустима. Общий `document.scrollWidth` недостаточен: внешняя обрезка скрывает переполнение.

H2 проходит по видимым внутренним ссылкам бонусных папок и проверяет HTTP200, компонент FolderPage, исходную личность, тестовую среду и продукт. Это защита от 404 по числовому slug папки; успешный код без правильного экрана не считается PASS. Передать `PF_BONUS_PRODUCT_ID` с подтверждённым доступом. Пустой список внутренних папок останавливает тест.

Подготовить на собственной тестовой учётке избранную силовую тренировку с таймкодами. Набор сам не добавляет и не удаляет избранное, не вводит пароль и блокирует записи. Передать приватные `PF_STORAGE_STATE`, `PF_EXPECTED_USER_ID`, `PF_TIMECODE_LESSON_ID`, проверенный HTTPS `BASE_URL` без завершающего слеша и такой же `PF_CONFIRMED_TEST_ORIGIN`, `QA_RUN_APPROVED=1` и новый свободный абсолютный `QA_DATA_LOCK_DIR`. Действительную тестовую среду дополнительно подтверждает серверное `isProduction=false`. Адреса и данные учёток в репозитории не хранятся.

Запуск без модели:

```sh
npx playwright test tests/popovichfit-program-ui.spec.js --workers=1 --output=work/gf6316-results --reporter=list
```

Отсутствие подходящих данных означает BLOCKED/FAIL, а не PASS. Видео/trace выключены; локальные кадры не публиковать. Набор не подтверждает переключение режима, прогресс, историю, RBAC, приложения и полный редизайн. Эти сценарии требуют самостоятельного принятого покрытия.
