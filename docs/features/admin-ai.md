# Admin AI: контракт следующего целевого набора

Готового AI integration suite в этом репозитории пока нет. Этот документ — входные
условия для реализации и QA; не результат AI автотестов и не PASS провайдера.
Messages geometry regression не проверяет AI ответы.

| Направление | Подтвердить до assertions | Как фиксировать факт |
|---|---|---|
| Точность | Approved вопрос, школа/роль, свежий источник ожидаемых данных, допустимые ответы/отказ/неопределённость | Сверить существенные утверждения и числовые значения с независимым серверным эталоном; UI включён не доказывает живой provider |
| Контекст / доступы | Какие поля видимой страницы разрешено передавать; роль и границы школы | Новый собственный чат с проверенным контекстом; проверить нужный school/user scope и отсутствие чужих данных |
| Задержка | Источник бюджета: первый ответ, полное завершение и UI timeout; streaming/retry/stop контракт | Измерять request→first visible output→complete, отдельно HTTP/provider/renderer время. Не выдумывать SLA по одному замеру |
| Usage | Что именно считает интерфейс: requests/messages/tokens/включённый лимит; поведение retry/stop/error | Записать baseline, один согласованный собственный запрос и изменение счётчиков; серверная сверка по подтверждённой схеме, не догадка по UI |
| Ошибки / повтор | Ожидаемый HTTP/provider error и доступное пользовательское действие | Новый запрос после исправления проверять отдельно от исторических ошибок; не считать старый400 новым отказом |

Для реализации нужен подтверждённый provider/test origin, разрешённые вопросы и
стоимость в согласованном объёме, независимые роли/эталоны, проверенный UI/API
контракт, ownership/journal/cleanup собственных чатов и privacy review доказательств.
При отсутствующем provider/ключе/эталоне — BLOCKED, не PASS и не автоматический баг
продукта. Дальше использовать [общий алгоритм](../ADDING-TESTS.md), adapter не
подменять фейковыми AI ответами. Native, accuracy/latency/usage integration пока
имеют статус NOT IMPLEMENTED / NOT RUN.
