# Для любой ИИ и разработчика

Прочитай и выполняй [RULES.md](RULES.md), затем [README.md](README.md),
[docs/WORKFLOW.md](docs/WORKFLOW.md) и актуальный docs/PROGRESS.md.
Для добавления автотестов следуй [docs/ADDING-TESTS.md](docs/ADDING-TESTS.md):
задача → diff/подтверждённый контракт → переиспользование → целевые проверки →
расследование красного → cleanup → фактический результат.

Работай в существующем feature suite; новый каркас не означает реализованное покрытие.
Не выдумывай локаторы/API/ожидания и не ослабляй assertion ради зелёного результата.
Сохраняй чужие изменения и оригинальные наборы; публикация и integration требуют
условий из RULES.md. Локальные unit/discovery не подтверждают работу продукта.
